# Буферный сборщик модуля мониторинга инцидентов с БПЛА на объектах ТЭК

Вспомогательный компонент ВКР «Разработка модуля информационно-аналитической системы
мониторинга и анализа инцидентов с применением БПЛА в отношении объектов ТЭК».

Основной стенд модуля (Docker Compose) работает на компьютере автора и не может опрашивать
источники круглосуточно. Буферный сборщик запускается GitHub Actions каждые 15 минут,
забирает новые сообщения тех же открытых источников (Telegram-каналы через `t.me/s/`,
Google News RSS) и сохраняет их в `data/*.jsonl`. При запуске стенда сообщения
импортируются в модуль (`services/collector/app/buffer_import.py` основного репозитория)
и проходят штатный путь: дедупликация по SHA-256(url+текст) → RabbitMQ → Classifier
Service → Incident Service. Классификация и корреляция в буфере не выполняются.

Формат строки `data/*.jsonl`:
`source_name, source_type, source_url, url, raw_text, published_at, fetched_at, content_hash`.

Догрузка пропуска: Actions → collect → Run workflow → since/until (например,
2026-09-26 / 2026-10-22). Telegram пролистывается назад параметром `?before=<id>`,
Google News — запросами с операторами `after:`/`before:` по окнам 3 суток.

Хранятся только публичные сообщения открытых источников.
